GearSimulator v2.0.1

FF14用の装備・マテリア・食事シミュレーターです。

配布ファイル
- GearSimulator.exe: Windows向け単体実行ファイル
- GearSimulator_v2.0.1_py.zip: Python 3.9向けソース配布
- SHA256SUMS.txt: SHA-256チェックサム

Windows版
1. GearSimulator.exeを書き込み可能な任意のフォルダへ配置します。
2. GearSimulator.exeを起動します。

Python版
1. Python 3.9を用意します。
2. py -3.9 -m pip install -r requirements.txt を実行します。
3. run_gui.batを実行します。

旧バージョンからの移行
- v2.0.1は旧バージョンと別のフォルダへ配置してください。
- 旧フォルダと同じ親フォルダへGearSimulator_v2.0.1として配置すると、初回起動時に設定と保存セットを引き継げます。
- 旧形式の保存スコアは「要再計算」と表示されます。

詳細はREADME.mdとCHANGELOG.mdを参照してください。
